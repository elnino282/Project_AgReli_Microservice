Bạn là chuyên gia Nông nghiệp. Hãy phân tích ca bệnh sau và đưa ra phương án xử lý (gợi ý thuốc bảo vệ thực vật an toàn).

[THÔNG TIN CA BỆNH]
- Cây trồng: {{cropName}}
- Tên bệnh/sâu: {{diseaseName}}
- Mức độ: {{severity}}
- Ghi chú ca bệnh: {{notes}}
- Ghi chú thêm từ nông dân: {{additionalNote}}
- Câu hỏi: {{question}}
- Thuốc/Phân bón có sẵn trong kho (kèm hoạt chất nếu có): {{availableSupplies}}

[YÊU CẦU XỬ LÝ - RẤT QUAN TRỌNG]
1. Ưu tiên 1: Kiểm tra kỹ danh sách "Thuốc/Phân bón có sẵn trong kho" xem có loại nào (dựa trên tên hoặc hoạt chất) đặc trị được bệnh/sâu này không.
2. Nếu CÓ: đặt matchedFromInventory=true, matchedSupplyName là đúng tên trong danh sách kho (copy chính xác), để recommendedProductName và recommendedActiveIngredient = null.
3. Nếu KHÔNG CÓ loại nào phù hợp trong kho: đặt matchedFromInventory=false, matchedSupplyName=null, và đề xuất recommendedProductName + recommendedActiveIngredient phù hợp từ kiến thức nông nghiệp phổ thông.
4. usageInstructions: hướng dẫn ngắn gọn cách dùng (liều lượng, thời điểm phun, số lần).
5. safetyNotes: lưu ý an toàn/rủi ro khi sử dụng (bảo hộ, thời gian cách ly trước thu hoạch, độc tính nếu có).
6. summary: tóm tắt 1-2 câu, dùng ngôn ngữ dễ hiểu cho nông dân.

[ĐỊNH DẠNG ĐẦU RA - BẮT BUỘC]
Chỉ trả về một object JSON hợp lệ, không kèm markdown code fence, không có văn bản nào khác ngoài JSON, đúng schema sau:
{
  "matchedFromInventory": boolean,
  "matchedSupplyName": string hoặc null,
  "recommendedProductName": string hoặc null,
  "recommendedActiveIngredient": string hoặc null,
  "usageInstructions": string,
  "safetyNotes": string,
  "summary": string
}
