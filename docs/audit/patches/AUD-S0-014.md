# AUD-S0-014 — Field log thuốc BVTV mặc định PHI bằng 0

**Trạng thái: FIXED 2026-08-14.**

## Reproduction evidence

- Farmer/employee tạo hoặc sửa field log loại `PESTICIDE_APPLICATION`/`SPRAY`.
- `FieldLogService` lưu log rồi gọi `PesticideRecordService.createFromFieldLog` trong cùng transaction.
- Method parse tên thuốc từ notes, khởi tạo `phiDays=0`; khi không match bảng reference theo tên/active ingredient, `.orElse(0)`.
- Bản ghi được lưu với `harvestAllowedDate = applicationDate + 0`, nên compliance downstream có thể coi an toàn ngay.
- Direct API `PesticideRecordService.create` lại yêu cầu reference hoặc PHI nhập tay và throw khi không xác định; hai entry path áp dụng invariant khác nhau.

## Root cause chain

`field-log request/notes -> FieldLogService -> createFromFieldLog heuristic parser -> pesticide reference miss -> season_db.pesticide_records(phi_days=0) -> harvest/marketplace PHI checks`

## Contract quyết định

- Owner: season-service PHI source record.
- Không match reference không đồng nghĩa zero-day PHI. Entry path từ field log phải yêu cầu dữ liệu structured/PHI hợp lệ hoặc fail transaction bằng typed 4xx.
- Không tạo pesticide record “Unknown/General Pesticide” với zero-day safe default.

## Patch boundary

- In scope: thống nhất validation giữa direct create và field-log-derived create; transaction rollback; typed error/test.
- Explicitly out of scope: OCR/AI nhận diện thuốc, tự chọn reference gần đúng, sửa tự động dữ liệu lịch sử.
- Compatibility: cần audit query cho record `field_log_id IS NOT NULL AND phi_days=0`; không tự thay PHI lịch sử nếu thiếu evidence.
- Rollback: revert code; không migration phá hủy.

## Regression and acceptance

- Unit/service: unknown notes -> typed error và không lưu cả field log/pesticide record; known reference -> đúng PHI; manual/direct path giữ validation.
- DB: không xuất hiện record derived mới với `phi_days=0` do lookup miss.
- E2E: tạo SPRAY unknown bị báo cần bổ sung PHI; known pesticide hiển thị harvest allowed date sau reload.
- Verify: targeted `FieldLogService`/`PesticideRecordService` tests và season `mvn test`.
