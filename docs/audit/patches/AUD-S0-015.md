# AUD-S0-015 — Xóa variety fail-open khi season lookup lỗi

**Trạng thái:** `FIXED 2026-08-14`

## Reproduction evidence

- Persona: admin gọi `DELETE /api/v1/admin/varieties/{id}`; controller đúng role và mô tả phải 409 nếu đang được season tham chiếu.
- `VarietyService.delete` gọi Feign `GET /api/v1/public/seasons/exists-by-variety/{id}`.
- Không có controller mapping này trong season-service; chỉ có `SeasonQueryService.existsSeasonByVarietyId` chưa được expose.
- Feign fallback trả `false`; catch trong service cũng chỉ log và giữ `hasSeasons=false`, sau đó hard-delete variety.
- Database-per-service không có FK chéo, nên `season_db.seasons.variety_id` có thể trỏ tới catalog row đã mất.

## Root cause chain

`season_db.seasons -> method tồn tại nhưng thiếu controller contract -> Feign 404/outage -> fallback false/catch swallow -> VarietyService.delete -> crop_catalog_db delete`

## Contract quyết định

- Owner delete guard: crop-catalog-service; season-service cung cấp internal read contract.
- Tạo endpoint internal có test contract cho `existsByVariety`; Feign không dùng public URL cho service guard.
- Chỉ response thành công `false` mới cho phép xóa. 404 contract, timeout, 5xx hoặc parse failure phải typed 503/fail-closed và transaction không delete.

## Patch boundary

- In scope: internal endpoint + client mapping + fail-closed fallback/service test + security/network classification.
- Explicitly out of scope: soft-delete toàn catalog, migration FK cross-schema, cleanup dangling data cũ.
- Compatibility: endpoint additive; admin delete behavior đổi từ false-success thành 503 khi dependency unavailable.
- Rollback: revert code; không migration.

## Regression and acceptance

- Unit/service: referenced=true -> conflict/no delete; false -> delete; fallback/exception/null -> unavailable/no delete.
- Security: admin delete allowed qua gateway; wrong role/anonymous rejected; internal lookup không được gateway public-route.
- Contract/E2E: seed season tham chiếu variety, delete giữ cả hai DB; stop season-service, delete giữ catalog row.
- Verify: targeted crop-catalog + season controller tests, boundary script.

## Implementation evidence

- Regression đỏ xác nhận `InternalSeasonController` thiếu mapping, fallback trả `false`, và `VarietyService` nuốt exception/null rồi xóa.
- Season-service thêm additive internal contract `GET /api/v1/internal/seasons/exists-by-variety/{varietyId}`, gọi `SeasonQueryService.existsSeasonByVarietyId`; crop-catalog Feign đã chuyển khỏi URL public không tồn tại.
- Fallback và service đều trả `ERR_DOWNSTREAM_GUARD_UNAVAILABLE` HTTP 503 cho outage/null. Chỉ Boolean `false` từ response thành công mới cho phép hard-delete; referenced `true` giữ conflict cũ.
- H2 integration xác nhận cả referenced và downstream-down giữ variety row, verified-no-reference mới xóa. Security test xác nhận anonymous 401, FARMER 403, ADMIN 200.
- Verify ngày 2026-08-14: full crop-catalog 12/12; full season 17/17; `scripts/verify-compose-boundary.ps1` xanh, endpoint internal không trở thành gateway ingress.
- Cross-DB runtime seed/stop-service journey vẫn được lặp lại ở Giai đoạn 5; invariant, DB mutation boundary và security đã có regression tự động.
