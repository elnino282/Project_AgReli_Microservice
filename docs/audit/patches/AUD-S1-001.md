# AUD-S1-001 — Admin certification lifecycle

## Root cause

Route admin dùng endpoint list/approve không tồn tại, fallback sang mock và dùng trạng thái `PENDING_APPROVAL` không thuộc state machine backend (`SCHEDULED → IN_PROGRESS → PASSED/FAILED`). Response list thiếu farm, standard, record status và nonconformity nên UI không thể điều khiển lifecycle từ dữ liệu DB.

## Patch

- Thêm list-all ADMIN-only, enrich response từ certification record/farm/standard/nonconformity.
- FE bỏ mock, dùng API start/complete/nonconformity/issue thật và chỉ hiển thị action hợp lệ theo state machine.
- Số chứng nhận/ngày cấp/hết hạn do admin nhập, không sinh business identifier giả bằng `Date.now()`.

## Evidence

- Farm-service full 27/27; security anonymous/FARMER/ADMIN 3/3; persisted response invariant 1/1.
- Admin UI flow 1/1, frontend typecheck/lint (0 error)/build xanh ngày 2026-08-21.
