# AUD-S2-006 — Thay Tempo giả bằng tracing backend thật

**Trạng thái:** `FIXED` ngày 2026-08-21.

## Root cause

Service Compose tên `tempo` dùng image `mailhog/mailhog:latest`. Container có thể hiện `Up` nhưng không có HTTP readiness, OTLP receiver, trace storage hay query API; trạng thái observability vì vậy là false-positive.

## Acceptance contract

1. `tempo` dùng image Grafana Tempo được pin version và cấu hình single-binary cho local development.
2. OTLP gRPC `4317`, OTLP HTTP `4318`, query/readiness `3200` bind rõ `0.0.0.0`; trace lưu vào named volume riêng.
3. Grafana được provision Tempo datasource, không cần cấu hình tay sau mỗi lần tạo container.
4. Runtime `/ready` trả 200; một OTLP smoke span được ingest và tìm thấy qua Tempo search API.
5. Không bật tracing exporter của toàn bộ service trong patch này; sampling/export policy là quyết định vận hành riêng, tránh đổi tải runtime ngoài root cause.

## Rollback

Rollback Compose/config bằng `git revert`. Named volume `tempo_data` có thể giữ lại; không dùng `docker compose down -v`.

## Kết quả xác minh

- `docker compose config --quiet` xanh; 22 container ở trạng thái running, Gateway `UP`.
- Tempo `/ready` trả 200; synthetic OTLP HTTP span ingest 200 và query lại đúng trace qua `/api/traces/{id}` trả 200.
