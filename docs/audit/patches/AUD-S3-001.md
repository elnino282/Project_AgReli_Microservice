# AUD-S3-001 — Wire FDN vào dashboard sống

**Trạng thái:** `FIXED` ngày 2026-08-21.

## Root cause

Dashboard FDN cũ đã bị xóa khỏi route trong một commit trước, nhưng client/schema/hook thật vẫn còn. `FarmerDashboardPage` hiện là route sống nhưng chưa gọi sustainability overview, khiến contract FDN hợp lệ chỉ được test mà không có consumer UI.

## Acceptance contract

1. Route `/farmer/dashboard` gọi farm-level `useDashboardFdnOverview`; season đang chọn được giữ làm context cho các link nhập liệu workspace.
2. UI chỉ hiển thị số liệu/recommendation backend; null, unavailable và error phải hiện rõ, không suy diễn điểm số.
3. Các endpoint FDN client được đối chiếu với controller sustainability hiện hành.
4. Component regression, FDN contract test, typecheck và build xanh.

## Rollback

Frontend-only, không migration; rollback bằng `git revert` patch mang mã `AUD-S3-001`.
