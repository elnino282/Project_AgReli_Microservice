# AUD-S3-007 — Đồng bộ run guide và local ports

**Trạng thái:** `FIXED` ngày 2026-08-21.

## Root cause

`RUN_GUIDE.md` còn ghi frontend 5173/gateway 8000 và thiếu delivery 8092, trong khi Vite/Compose hiện hành dùng 3000/8080. Default proxy trong `vite.config.ts` cũng còn 8000, chỉ được che nếu `.env.development` có override.

## Acceptance contract

1. Vite default proxy, run guide và Compose thống nhất frontend 3000, gateway 8080.
2. Guide dùng `npm ci`, `docker compose up --wait`, readiness command và danh sách đủ 12 runtime service.
3. Không hướng dẫn reset volume như cách sửa lỗi mặc định; thao tác xóa dữ liệu phải là cảnh báo cuối cùng.
4. Local smoke xác minh frontend/backend endpoint trả HTTP thành công.

## Rollback

Docs/config frontend-only; rollback bằng `git revert`.

## Verification

- `RUN_GUIDE.md` và Vite default proxy dùng 3000/8080, liệt kê đúng 12 service nội bộ và lệnh readiness không xóa volume.
- `npm run demo:smoke` kiểm tra frontend, bốn persona, dashboard/admin/marketplace và ba route FDN qua Vite proxy; kết quả `LOCAL_DEMO_SMOKE=PASS`.
- Compose có 22 container running, không container unhealthy và gateway health `UP`.
