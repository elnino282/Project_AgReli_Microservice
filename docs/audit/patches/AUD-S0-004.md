# AUD-S0-004 — Marketplace publish/compliance state transition

## Invariant

- Farmer chỉ có thể gửi listing sang review, rút listing về draft hoặc ẩn listing đang bán.
- Chỉ admin mới đưa listing sang trạng thái sellable (`ACTIVE`/`PUBLISHED`), và cả hai trạng thái đều phải qua compliance gate trước khi ghi DB.

## Reproduction trước fix

- Service test gọi farmer status API với `DRAFT -> ACTIVE`: code gán trực tiếp enum và đi tới save/event thay vì từ chối.
- Service test gọi admin `PENDING_REVIEW -> ACTIVE`: `MarketplaceComplianceGateService` không được gọi vì code chỉ guard `PUBLISHED`.
- Frontend seller tạo trực tiếp request `INACTIVE/HIDDEN -> ACTIVE`.

Các regression test trên đều đỏ trước patch implementation.

## Root cause

Một DTO enum dùng chung cho farmer/admin nhưng invariant chuyển trạng thái không nằm trong service owner. Hệ thống đồng thời coi cả `ACTIVE` và `PUBLISHED` là public/sellable trong repository, trong khi compliance chỉ kiểm tra `PUBLISHED`.

## Thiết kế fix

- Enforce allow-list chuyển trạng thái farmer tại `MarketplaceServiceImpl`.
- `INACTIVE`, `HIDDEN`, `REJECTED`, `SOLD_OUT` phải quay lại `PENDING_REVIEW`; không được tự kích hoạt.
- Compliance gate chạy cho cả `ACTIVE` và `PUBLISHED`; snapshot, claim, thời điểm kiểm tra và `publishedAt` được ghi cùng transaction.
- Cập nhật action frontend để khớp contract; không sửa generated client bằng tay.

## Compatibility và rollback

Response shape không đổi. Request trước đây tự kích hoạt listing sẽ nhận 409 và phải resubmit review. Rollback bằng `git revert`; không có migration.

## Acceptance

- Farmer direct publish/activate bị từ chối và repository không save.
- Farmer submit/withdraw/hide hợp lệ.
- Admin chuyển sang mọi trạng thái sellable đều gọi compliance; compliance fail không save.
- Unit/service tests backend và transition test frontend xanh.
