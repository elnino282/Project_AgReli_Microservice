# AUD-S1-005 — Contract tải hồ sơ VietGAP

## Trạng thái trước patch

- Route sống `/farmer/farms/:farmId/certification` gọi `POST /api/v1/farms/{farmId}/certification/export-dossier`.
- Backend công bố và trả `ApiResponse<FarmDocumentResponse>`; `result.fileUrl` là vị trí nội dung tài liệu đã được lưu vết trong `farm_documents`.
- Frontend bỏ qua `FarmDocumentResponse`, bọc toàn bộ object JSON vào `Blob` rồi gắn tên `.zip`. File tải xuống vì vậy không phải ZIP hợp lệ và không chứa đúng nội dung dossier.
- Định dạng PDF/ZIP và lưu MinIO vẫn được BRD đánh dấu `[CẦN XÁC NHẬN định dạng]`; không mở rộng sản phẩm trong patch sửa contract này.

## Acceptance contract

1. API adapter trả kiểu `FarmDocumentResponse`, không dùng `any`/blob giả định.
2. UI dùng trực tiếp `result.fileUrl` do backend trả về và tên file phản ánh MIME hiện hành (`text/plain`), không tạo object URL từ JSON response và không gắn đuôi ZIP giả.
3. Thiếu/không hợp lệ `fileUrl` phải báo lỗi, không toast thành công giả.
4. Regression test chứng minh click export dùng URL tài liệu persisted và tên file đúng.
5. Typecheck, lint, frontend build và farm-service regression phải xanh; OpenAPI source contract không đổi.

## Rollback

Patch chỉ thay consumer frontend và test/tài liệu, có thể rollback độc lập bằng `git revert` commit mang mã `AUD-S1-005`; không có migration hoặc thay đổi dữ liệu.

## Evidence

- Test đỏ trước patch: route export không click URL persisted và kỳ vọng `data:text/plain` nhận chuỗi rỗng.
- Sau patch: API contract 1/1, route UI 2/2 và tổng S1 frontend targeted 8/8 xanh.
- S1 regression: farm 27/27, season 21/21, delivery 21/21, marketplace 49/49; frontend typecheck, lint (0 error, warning debt cũ) và production build xanh ngày 2026-08-21.
