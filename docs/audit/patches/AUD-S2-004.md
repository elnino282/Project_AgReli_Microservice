# AUD-S2-004 — RAG dùng Chroma và embedding thật

**Trạng thái:** `FIXED` ngày 2026-08-21.

## Root cause

`AiApplication` loại `ChromaVectorStoreAutoConfiguration`; `AiConfig` sau đó đăng ký `@Primary` dummy `VectorStore` luôn trả empty và dummy `EmbeddingModel` luôn trả vector zero. Ingestion báo thành công dù không lưu gì, chat nhìn như đã chạy RAG nhưng không thể lấy nguồn. Cấu hình Chroma còn truyền URL có port vào thuộc tính `host`, trong khi starter ghép `host:port` riêng.

## Acceptance contract

1. Không còn dummy/zero embedding hoặc vector store trả empty cố định.
2. Chroma auto-configuration được bật, host và port tách đúng contract Spring AI.
3. Embedding dùng Gemini `text-embedding-004` với API key cấu hình; thiếu key phải fail rõ khi gọi embedding, không tạo vector giả.
4. Unit test kiểm tra wiring không exclude Chroma, không dummy bean và embedding fail-closed khi thiếu key.
5. `ai-service` test/build và runtime health với Chroma phải xanh.

## Rollback

Không migration dữ liệu. Rollback code/config bằng `git revert`; collection Chroma hiện hành giữ nguyên.

## Kết quả xác minh

- Full `ai-service`: 14/14 test xanh, gồm wiring fail-closed và source mapping.
- Runtime `ai-service` healthy; Chroma v2 có tenant/database/collection `acm_knowledge` thật.
