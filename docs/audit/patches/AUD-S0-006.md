# AUD-S0-006 — PHI snapshot contract and unknown state

## Invariant

Public trace chỉ được tuyên bố PHI an toàn khi marketplace đã lưu và deserialize thành công snapshot đúng schema. Thiếu hoặc hỏng snapshot là `UNKNOWN`, không phải `SAFE`.

## Reproduction trước fix

- Compliance gate serialize `List<PesticideRecordDto>` (hoặc chuỗi `[]`).
- Public trace deserialize JSON đó thành `PHISafetyInfo`, nên snapshot hợp lệ lúc ghi không thể đọc đúng lúc public.
- Frontend dùng `phiSafety?.safe ?? true`; null sau lỗi deserialize được hiển thị thành “An toàn”.

## Root cause và fix

Producer/consumer dùng hai schema khác nhau. Compliance gate được đổi để tạo trực tiếp `PHISafetyInfo`; UI phân biệt `UNKNOWN` và `SAFE` thay vì default true.

Snapshot cũ dạng array được coi là unknown; listing phải qua compliance lần nữa để có snapshot mới. Không có migration, rollback bằng `git revert`.

Patch này chỉ đóng schema/unknown-state. Nhánh claim null/`NONE` bỏ qua toàn bộ PHI check là finding riêng `AUD-S0-011` và vẫn mở.

## Acceptance

- Snapshot producer deserialize được bằng DTO consumer.
- Danh sách thuốc rỗng tạo snapshot safe với count 0.
- Missing/corrupt snapshot không tạo claim safe trên UI.
