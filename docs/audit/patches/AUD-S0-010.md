# AUD-S0-010 — Auth refresh phá vỡ storage provenance và response contract

**Trạng thái:** `FIXED 2026-08-14`

## Reproduction evidence

- Persona/precondition: user đăng nhập với `rememberMe=false`; `AuthContext` lưu `acm_auth` trong `sessionStorage` với token và user.
- Trigger: một request nhận HTTP 401 và response interceptor trong `src/shared/api/http.ts` gọi `POST /api/v1/auth/refresh`.
- Expected: token mới được đọc từ `ApiResponse.result`, ghi đè đúng `sessionStorage`, giữ nguyên user metadata và request ban đầu được retry một lần.
- Actual tĩnh:
  - identity trả `ApiResponse<AuthenticationResponse>`; `AuthenticationResponse` chỉ có `token`/`expiresIn`, không có `refreshToken`.
  - interceptor destructure `token`, `refreshToken`, `expiresIn` trực tiếp từ `response.data`, nên cả ba đều `undefined` với response thật.
  - object lỗi được ghi vào `localStorage`; `JSON.stringify` bỏ token và chuyển `NaN` thành `null`.
  - `localStorage` được đọc trước `sessionStorage`, nên record lỗi che record session hợp lệ; user metadata cũng bị bỏ.
- Không log token thật. Runtime browser test chưa chạy trong Giai đoạn 3 vì frontend chưa có test interceptor và Docker Desktop bị quá tải; code path và contract hai đầu đủ để xác nhận tĩnh.

## Root cause chain

`identity AuthenticationResponse/ApiResponse envelope -> gateway -> http.ts raw Axios interceptor -> duplicate auth storage helpers -> AuthContext bootstrap`

- Token lifecycle bị triển khai hai lần ở `AuthContext.tsx` và `http.ts`, nhưng chỉ `AuthContext` biết storage provenance.
- Interceptor bỏ qua `sessionApi`/Zod envelope adapter.
- Tên `refreshToken` ở FE gây hiểu sai contract: backend hiện rotate chính access token cũ và trả một token mới, không phát refresh token riêng.

## Contract quyết định

- Owner: frontend session/auth boundary; backend identity contract không cần đổi trong patch tối thiểu.
- Interceptor phải đọc `response.data.result.token` và `result.expiresIn` theo schema hiện hành.
- Record auth sau refresh phải giữ `user` và được ghi lại đúng storage đã chứa record nguồn; storage còn lại phải không thể shadow bằng record cũ/lỗi.
- Nếu payload refresh thiếu token hợp lệ, coi refresh thất bại, không ghi storage và không retry bằng token rỗng.
- Giữ single-flight refresh; refresh 401 phải clear cả hai storage và chuyển về sign-in. Các lỗi 5xx không được âm thầm phá record hiện có.

## Patch boundary

- In scope: hợp nhất helper đọc/ghi auth hoặc trả kèm storage provenance; parse envelope; giữ user; test local/session và concurrent 401.
- Explicitly out of scope: thiết kế refresh-token/cookie mới ở identity-service, thay đổi thời hạn JWT, OAuth flow mới.
- Compatibility: đọc được record `acm_auth` hiện hành. Record malformed không có token/user bị clear có chủ đích.
- Rollback: `git revert` patch frontend; không migration/DB.

## Regression and acceptance

- Unit: session-only refresh không tạo local record; remember-me refresh ở local; user giữ nguyên; malformed envelope không ghi; hai 401 đồng thời chỉ gọi refresh một lần.
- Contract: fixture đúng `ApiResponse<AuthenticationResponse>` và không giả field `refreshToken`.
- Browser: login `rememberMe=false` -> ép 401 -> refresh -> reload cùng tab vẫn đăng nhập; đóng tab/mở session mới không còn đăng nhập.
- Verify: `npm run test -- --run <auth/http tests>`, `npm run typecheck`, `npm run lint`.

## Implementation evidence

- Regression đỏ xác nhận refresh boundary chưa testable; static chain đã chỉ ra token bị đọc sai level, user/source storage bị mất.
- `http.ts` parse `response.data.result.token/expiresIn`; token mới tiếp tục là credential refresh theo contract identity hiện hành, không giả field backend không phát.
- Reader validate đầy đủ record và xóa riêng record malformed trước khi thử storage còn lại. Writer giữ `user`, ghi đúng local/session nguồn và xóa stale copy để không shadow.
- Single-flight dùng một promise; malformed response không ghi/retry, refresh 401 clear cả hai storage, 5xx giữ auth. Response interceptor loại chính `/api/v1/auth/refresh` khỏi retry để tránh self-deadlock.
- Verify ngày 2026-08-14: interceptor/storage 8/8; auth regression 12/12; typecheck xanh; lint `--quiet` 0 error; production build xanh. Warning act/circular chunk/size là debt có sẵn ngoài patch.
- Browser journey login session → forced 401 → reload/close tab được giữ cho Giai đoạn 5; storage, retry và failure semantics đã có adapter/unit regression.
