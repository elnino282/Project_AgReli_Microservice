# AUD-S1-002 — Production diary sustainability routing

## Root cause và patch

Season mặc định gọi sustainability ở port incident 8088 và Compose không truyền URL, làm Feign fallback empty. Default được sửa thành 8089 và Compose truyền `APP_SUSTAINABILITY_SERVICE_URL=http://sustainability-service:8089`.

## Evidence

- Season compilation và actual-date regression 3/3 xanh.
- Compose config hợp lệ; season-service runtime healthy ngày 2026-08-21 với cấu hình mới.
