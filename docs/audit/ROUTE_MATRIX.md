## Gateway và network boundary

- Mọi request trên đi qua gateway 8080 (audit: `127.0.0.1:18080`); feature code không gọi host port service trực tiếp.
- Compose không publish 8081–8092. Giai đoạn 3 chạy host TCP matrix và cả 12 port đều đóng; gateway config không có route `/api/v1/internal/**`. `AUD-S0-002` đóng cho single-host Compose.
- Lỗi Chroma healthcheck quan sát ở baseline đầu đã được fix và full Compose wait/gateway health xanh; lịch sử failure/acceptance nằm trong `BASELINE.md` và `AUD-S1-006`.
